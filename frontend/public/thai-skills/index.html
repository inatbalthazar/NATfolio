ภาษาไทยที่อ่านเหมือนแปลมา เหมือนคนไทยเขียน Thai that reads translated native

skill ฟรีสามตัวที่สอน AI ให้แปลซับ เกม แอป และเว็บเป็นภาษาไทย เขียนบทละครสั้นที่ทำด้วยวิดีโอ AI และเกลาข้อความไทยให้อ่านเหมือนคนเขียน ใช้กับ Claude, ChatGPT, Gemini, Codex, Copilot และ Cursor

Three free skills that teach your AI to translate subtitles, games, apps and websites into Thai, write Thai dialogue for AI short dramas, and make AI-written Thai read like a person wrote it. Works with Claude, ChatGPT, Gemini, Codex, Copilot and Cursor.

$ npx humanizer-th

พิมพ์ใน Terminal แล้วสั่งงานได้เลย ใช้ ChatGPT หรือ Gemini ดูวิธีตรงนี้

Run it in a terminal, then just ask. Using ChatGPT or Gemini? See here.

สามงานที่ AI ยังทำภาษาไทยได้ไม่ดีThree jobs AI still does badly in Thai

ติดตั้งครั้งเดียวได้ทั้งสามตัว แล้ว AI จะเลือกตัวที่ตรงกับงานเอง

Install all three at once. The AI picks the right one for each request.

  • แปลซับ เกม แอป และเว็บSubtitles, games, apps and websiteslocalize-th

    แปลอังกฤษเป็นไทยจากไฟล์ SRT, VTT, ASS, JSON, PO, XLIFF, .strings และ Android XML เวลาในซับ key และตัวแปรไม่พัง บรรทัดซับไม่ยาวเกินอ่านทัน เลือกสรรพนามตามความสัมพันธ์ของตัวละคร และมีสคริปต์เทียบไฟล์กับต้นฉบับ

    English to Thai from SRT, VTT, ASS, JSON, PO, XLIFF, .strings and Android XML. Timings, keys and placeholders survive, subtitle lines stay readable, pronouns fit each relationship, and a checker diffs the file against the source.

    พิมพ์ว่าAskแปลซับนี้เป็นไทยTranslate this strings file into Thai

  • บทละครสั้น AI และเสียงพากย์AI short dramas and voice-overscript-th

    เขียนบทจากไอเดียหรือเกลาบทเดิม แบ่งให้พอดีคลิปละไม่กี่วินาที ทำพรอมต์ทีละช็อตโดยใช้คำบรรยายตัวละครชุดเดียวกันทุกช็อต และเตรียมบทให้เสียง AI อ่านตัวเลขและคำยากถูก

    Write from an idea or polish a script, split it into clips a few seconds long, write per-shot prompts with one fixed character description, and prepare voice scripts Thai TTS reads correctly.

    พิมพ์ว่าAskเขียนบทละครสั้นเรื่อง...Write a Thai short drama about...

  • ข้อความที่ AI เขียนAI-written Thaihumanizer-th

    โพสต์ อีเมล และข้อความ LINE ให้อ่านเหมือนคนเขียน ตรวจ 29 รูปแบบที่คนไทยอ่านแล้วรู้ทันที หรือส่งโพสต์เก่าไปให้ดู แล้วให้เขียนเป็นสำนวนของเราเอง

    Posts, emails and chat messages that read like a person wrote them. It checks 29 patterns Thai readers spot at once, or writes in your own voice from samples of your past writing.

    พิมพ์ว่าAskเกลาให้หน่อยMake my Thai sound natural

เริ่มใช้Get started

คำสั่งเดียว ไม่ต้องตั้งค่าอะไรเพิ่ม

One command. Nothing to configure.

  1. ติดตั้งInstall

    ผ่านVia

    เปิด Terminal (Mac) หรือ PowerShell (Windows) แล้วพิมพ์

    Open Terminal (Mac) or PowerShell (Windows) and run

    $ npx humanizer-th

    ลงให้ Claude Code, Codex, Gemini CLI และ GitHub Copilot ที่มีในเครื่อง ต้องมี Node.js ถ้าขึ้นว่า Ok to proceed ให้กด y

    Installs for Claude Code, Codex, Gemini CLI and GitHub Copilot, whichever you have. Needs Node.js. If it asks "Ok to proceed", press y.

    อัปเดต ลบ และวิธีอื่นUpdate, remove and other ways

    อัปเดตUpdate

    npx humanizer-th@latest

    ลบRemove

    npx humanizer-th uninstall

    plugin ของ Claude Code (พิมพ์ใน Claude Code)Claude Code plugin (run inside Claude Code)

    /plugin marketplace add inatbalthazar/humanizer-th /plugin install humanizer-th@humanizer-th

    Cursor, Windsurf และตัวอื่นที่ skills CLI รู้จักCursor, Windsurf and other Skills CLI agents

    npx skills add inatbalthazar/humanizer-th --global --agent '*'

    ดาวน์โหลด zip ของ skill ที่ต้องการ แล้วอัปโหลดทีละไฟล์ใน Settings → Capabilities → Skills ไม่ต้องแตก zip

    Download the zip for each skill you want and upload them one at a time under Settings → Capabilities → Skills. Don't unzip them.

    localize-th.zip script-th.zip humanizer-th.zip

    ถ้าในหน้านั้นมีสวิตช์ code execution ให้เปิดด้วย

    If that page has a code execution switch, turn it on too.

    ดาวน์โหลดไฟล์ของ skill ที่ต้องการ

    Download the file for each skill you want.

    localize-th-prompt.md script-th-prompt.md humanizer-th-prompt.md

    ChatGPT สร้าง GPT ใหม่ อัปโหลดไฟล์ในช่อง Knowledge แล้วพิมพ์ในช่อง Instructions ว่า "ทำตามคำสั่งในไฟล์ [ชื่อไฟล์] ทุกข้อ"

    ChatGPT Create a GPT, upload the file under Knowledge, and set Instructions to "Follow every instruction in [file name]."

    Gemini สร้าง Gem แล้ววางเนื้อหาทั้งไฟล์ในช่องคำสั่ง

    Gemini Create a Gem and paste the whole file into its instructions.

  2. เปิดโปรแกรมใหม่Restart your tool

    ปิดแล้วเปิด Claude Code, Codex หรือโปรแกรมที่ใช้อีกครั้ง ใช้ GPT หรือ Gem ข้ามขั้นนี้ได้

    Close and reopen Claude Code, Codex or whatever you use. Skip this for a GPT or Gem.

  3. พิมพ์สั่งได้เลยJust ask

    ไม่ต้องจำคำสั่ง เช่น "แปลซับนี้เป็นไทย" แล้วแนบไฟล์ หรือ "เกลาให้หน่อย" แล้ววางข้อความ

    No commands to remember. "Translate this subtitle file into Thai" with the file attached is enough.

อ่านไทยไม่ออกก็ใช้ได้If you don't read Thai

  • สั่งเป็นภาษาอังกฤษได้ งานที่ได้ยังเป็นภาษาไทย แต่บันทึกและคำอธิบายจะเป็นภาษาอังกฤษ
  • งานสั้นมีคำแปลกลับเป็นภาษาอังกฤษให้ตรวจความหมาย ไฟล์ยาวขอเพิ่มได้
  • เหมาะกับบริษัทเกมและแอปต่างชาติที่จะออกเวอร์ชันไทย
  • Ask in English. The Thai stays Thai; notes and explanations come back in English.
  • Short jobs include a back-translation so you can check the meaning. Ask for one on longer files.
  • Have a native Thai speaker review anything you publish.

ควรรู้ก่อนใช้Good to know

  • skill คือคำแนะนำที่ AI ทำตาม ไม่ใช่โปรแกรม ผลแต่ละครั้งไม่เหมือนกันเป๊ะ ควรอ่านทวนก่อนใช้จริง
  • ทดสอบกับ Claude เป็นหลัก ตัวอื่นใช้ได้ แต่ผลขึ้นกับว่าโมเดลเก่งภาษาไทยแค่ไหน
  • ไม่ได้มีไว้หลบ AI detector และไม่เขียนในนามคนอื่น
  • Skills are guidance the AI follows, not programs, so results vary. Review before you use them.
  • Tested mostly with Claude. Other models work, depending on how well they handle Thai.
  • Not an AI-detector evasion tool, and it won't write as someone else.
