Thai skills for AI

ให้ AI ทำงานภาษาไทย แบบคนไทย Thai that doesn't read like a translation

ชุด skill ฟรีสามตัว แปลซับ เกม แอป และเว็บเป็นภาษาไทย เขียนบทละครสั้นที่ทำด้วยวิดีโอ AI และเกลาข้อความไทยที่ AI เขียนให้อ่านเป็นธรรมชาติ ใช้กับ Claude, ChatGPT, Gemini, Codex, Copilot และ Cursor

Three free skills for your AI: translate subtitles, games, apps and websites into natural Thai, write Thai dialogue for AI short dramas, and polish AI-written Thai. Works with Claude, ChatGPT, Gemini, Codex, Copilot and Cursor.

สามตัว ใช้คนละงานThree skills

ติดตั้งครั้งเดียวได้ทั้งสามตัว AI จะเลือกตัวที่ตรงกับคำสั่งเอง

Install them together. The AI picks the right one for each request.

localize-th

แปลอังกฤษเป็นไทยEnglish to Thai

ซับหนังและซีรีส์ (SRT, VTT, ASS) บทพากย์ ข้อความในแอปและเว็บ (JSON, PO, XLIFF, .strings, Android XML) และเกม เวลาในซับ key และตัวแปรไม่พัง บรรทัดซับไม่ยาวจนอ่านไม่ทัน และเลือกสรรพนามตามความสัมพันธ์ของตัวละคร

Subtitles (SRT, VTT, ASS), dubbing scripts, app and website strings (JSON, PO, XLIFF, .strings, Android XML) and games. Timings, keys and placeholders stay intact, subtitle lines stay readable, and pronouns fit each character relationship.

ละครสั้น AI และเสียงพากย์AI short dramas and voice-over

ติดตั้งInstall

คำสั่งเดียว แล้วพิมพ์สั่งงานเป็นภาษาไทยได้เลย ไม่ต้องตั้งค่าอะไรเพิ่ม

One command, then just ask. Nothing else to set up.

  1. 1

    ติดตั้งInstall the skills

    ติดตั้งผ่านInstall via

    เปิด Terminal (Mac) หรือ PowerShell (Windows) แล้วพิมพ์

    Open Terminal (Mac) or PowerShell (Windows) and run

    $ npx humanizer-th

    ติดตั้งทั้งสามตัวให้ Claude Code, Codex, Gemini CLI และ GitHub Copilot ที่มีในเครื่อง ต้องมี Node.js ถ้าขึ้นว่า Ok to proceed ให้กด y

    Installs all three for Claude Code, Codex, Gemini CLI and GitHub Copilot, whichever you have. Needs Node.js. If it asks "Ok to proceed", press y.

    อัปเดต ลบ และวิธีอื่นUpdates, removal and other ways

    อัปเดตUpdate

    npx humanizer-th@latest

    ลบRemove

    npx humanizer-th uninstall

    plugin ของ Claude Code (พิมพ์ใน Claude Code)Claude Code plugin (run inside Claude Code)

    /plugin marketplace add inatbalthazar/humanizer-th /plugin install humanizer-th@humanizer-th

    Cursor, Windsurf และตัวอื่นที่ skills CLI รู้จักCursor, Windsurf and other Skills CLI agents

    npx skills add inatbalthazar/humanizer-th --global --agent '*'

    ดาวน์โหลด zip ของ skill ที่ต้องการ แล้วอัปโหลดทีละไฟล์ใน Settings → Capabilities → Skills ไม่ต้องแตก zip

    Download the zip for each skill you want, then upload them one at a time under Settings → Capabilities → Skills. Don't unzip them.

    localize-th.zip script-th.zip humanizer-th.zip

    ถ้าในหน้านั้นมีสวิตช์ code execution ให้เปิดด้วย

    If the page has a code execution switch, turn it on too.

    ดาวน์โหลดไฟล์ของ skill ที่ต้องการ

    Download the file for each skill you want.

    localize-th-prompt.md script-th-prompt.md humanizer-th-prompt.md

    ChatGPT: สร้าง GPT ใหม่ อัปโหลดไฟล์ในช่อง Knowledge แล้วพิมพ์ในช่อง Instructions ว่า "ทำตามคำสั่งในไฟล์ [ชื่อไฟล์] ทุกข้อ"

    ChatGPT: create a GPT, upload the file under Knowledge, and set Instructions to "Follow every instruction in [file name]."

    Gemini: สร้าง Gem แล้ววางเนื้อหาทั้งไฟล์ในช่องคำสั่ง

    Gemini: create a Gem and paste the whole file into its instructions.

  2. 2

    เปิดโปรแกรมใหม่Restart your tool

    ปิดแล้วเปิด Claude Code, Codex หรือโปรแกรมที่ใช้อีกครั้ง ถ้าใช้ GPT หรือ Gem ข้ามขั้นนี้ได้

    Close and reopen Claude Code, Codex or whatever you use. Skip this for a GPT or Gem.

  3. 3

    พิมพ์สั่งได้เลยJust ask

    ไม่ต้องจำคำสั่ง AI จะเลือก skill ที่ตรงกับงานเอง

    No commands to remember. The AI picks the right skill.

    แปลซับนี้เป็นไทยเขียนบทละครสั้นเรื่อง...เกลาให้หน่อย Translate this subtitle file into ThaiMake my Thai sound natural

สำหรับคนที่อ่านไทยไม่ออกIf you don't read Thai

  • สั่งเป็นภาษาอังกฤษได้ งานที่ได้ยังเป็นภาษาไทย
  • บันทึก สรุป และคำถาม จะเป็นภาษาอังกฤษ
  • งานสั้นมีคำแปลกลับเป็นภาษาอังกฤษให้ตรวจความหมาย ไฟล์ยาวขอเพิ่มได้
  • เหมาะกับบริษัทเกมและแอปต่างชาติที่จะออกเวอร์ชันไทย
  • Ask in English. The Thai output stays Thai.
  • Notes, summaries and questions come back in English.
  • Short jobs include a back-translation so you can check the meaning. Ask for one on longer files.
  • Have a native Thai speaker review anything you publish.

ควรรู้ก่อนใช้Good to know

  • skill คือคำแนะนำที่ AI ทำตาม ไม่ใช่โปรแกรม ผลแต่ละครั้งจึงไม่เหมือนกันเป๊ะ ควรอ่านทวนก่อนใช้จริง
  • ทดสอบกับ Claude เป็นหลัก ตัวอื่นใช้ได้ แต่ผลขึ้นกับว่าโมเดลเก่งภาษาไทยแค่ไหน
  • ไม่ได้มีไว้หลบ AI detector และไม่เขียนในนามคนอื่น
  • Skills are guidance the AI follows, not programs, so results vary. Review before you use them.
  • Tested mostly with Claude. Other models work, depending on how well they handle Thai.
  • Not an AI-detector evasion tool, and it won't write as someone else.
